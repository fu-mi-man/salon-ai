# ログイン画面

**ルーティング**: `/login`  
**対象ユーザー**: owner / staff  
**主な目的**: Webアプリへのログインとパスワードリセット導線の提供  

## 前提

- フェーズ1は**最小MVPとして** owner / staff の個別ログインのみ実装する
- 初期アカウントは開発者が事前に発行する
- サインアップ画面・招待画面は提供しない

## シナリオ

開発者から案内されたメールアドレスとパスワードを受け取る  
→ ログインユーザーが `/login` を開く  
→ メールアドレスとパスワードを入力する  
→ 「ログイン」を押す  
→ 認証成功後に `/dashboard` へ遷移する  

## 画面構成

```text
ロゴ / サービス名

見出し: ログイン
説明文: 発行済みアカウントでログインしてください

メールアドレス入力
パスワード入力
ログインボタン

パスワードを忘れた場合リンク
```

## 入力項目

| 項目 | 内容 |
|---|---|
| メールアドレス | Supabase Auth に登録済みのメールアドレス |
| パスワード | 発行済みパスワード、または再設定後のパスワード |

## 操作

| 操作 | 挙動 |
|---|---|
| ログイン | email/password で認証する。成功時は `/dashboard` に遷移する |
| パスワードを忘れた場合 | `/reset-password` に遷移する |

## バリデーション

- メールアドレスが空の場合はエラー表示
- メールアドレス形式が不正な場合はエラー表示
- パスワードが空の場合はエラー表示

## 状態

| 状態 | 表示 |
|---|---|
| 送信中 | ログインボタンをローディング状態にし，再送信を防ぐ |
| 認証成功 | `/dashboard` に遷移する |
| 認証失敗 | フォーム下部に「メールアドレスまたはパスワードが正しくありません」を表示する |
| セッションあり | `/login` を表示せず `/dashboard` にリダイレクトする |

## 備考

- 新規登録リンクは置かない
- 初回ログイン後に各ユーザーが任意のパスワードへ変更できるよう，パスワードリセット導線を常に表示する
- SPファースト。入力欄とボタンは片手操作しやすい縦並びにする
